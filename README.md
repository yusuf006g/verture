# Trucking Loads Assistant (MVP)

Telegram-бот на Python 3.11 для разбора пересланных сообщений QM NOTIFIER, фотографий и PDF с данными о грузовых рейсах. Сохраняет оригинальный текст, извлечённые поля — в SQLite, умеет переводить текст на русский и экспортировать рейсы в Excel.

## Возможности

- Принимает текст/пересланные сообщения, изображения и PDF.
- Извлекает распространённые поля: Trip #, Ref #, commodity, адреса, appointment, тип остановки, тип прицепа, equipment, quantity, miles, rate.
- Сохраняет оригинальный английский текст и структурированные поля.
- Показывает значения на русском и сохраняет английские названия/оригинал.
- Конвертирует мили в километры (1 mi = 1.609344 km).
- SQLite и экспорт Excel.
- Если поле не найдено, пишет «Не указано»; бот не должен придумывать отсутствующие значения.

## Ограничения MVP

Парсер основан на правилах и рассчитан на типовые уведомления QM NOTIFIER. Разные форматы сообщений могут требовать доработки `bot/parser.py`. Перевод использует онлайн-сервис Google Translate через `deep-translator`: нужен интернет; не отправляй туда конфиденциальные данные без разрешения работодателя. Для OCR изображений нужен Tesseract. Текстовые PDF поддерживаются; для сканированных PDF может понадобиться OCR-конвертация в изображение. Этот MVP не проверяет истинность адресов, тарифов или appointment и не заменяет проверку диспетчером.

## Установка на macOS

1. Установи Python 3.11, если его ещё нет:
   ```bash
   python3.11 --version
   ```
2. Распакуй архив и перейди в папку:
   ```bash
   cd trucking_loads_bot
   ```
3. Создай виртуальное окружение и установи зависимости:
   ```bash
   python3.11 -m venv .venv
   source .venv/bin/activate
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```
4. Для OCR изображений установи Tesseract:
   ```bash
   brew install tesseract
   ```
   Если Homebrew не установлен, OCR можно пропустить — бот всё равно обработает текст и PDF с выделяемым текстом.
5. Скопируй настройки:
   ```bash
   cp .env.example .env
   ```
   Открой `.env` в редакторе и вставь токен от BotFather в `BOT_TOKEN`.
6. Запусти:
   ```bash
   python main.py
   ```

## Как пользоваться

- Открой своего бота и нажми `/start`.
- Перешли ему сообщение QM NOTIFIER или отправь текст.
- Отправь скриншот как фото/изображение либо PDF.
- `/loads` — последние сохранённые рейсы.
- `/search 2327` — поиск по номеру рейса.
- `/export` — создать и отправить Excel-файл.
- `/help` — список команд.

## Безопасность

- Никогда не публикуй `.env` и токен бота.
- Добавь `.env` в `.gitignore` (уже включено).
- В MVP нет разграничения пользователей: любой, кто может написать боту, может обрабатывать и экспортировать данные. Для рабочей эксплуатации добавь список разрешённых Telegram user ID.
- Бот обрабатывает только те сообщения, которые ему переслали/отправили. Он не читает личные чаты пользователя сам по себе.
